# 금융 데이터 분석 포트폴리오

Python으로 주식 투자전략을 비교하고, 금리 변화에 따른 채권 자산과 부채의 가치 변화를 분석하였다. 각 프로젝트 폴더에 분석 과정과 실행 결과를 담은 Jupyter Notebook, 주요 결과를 정리한 README를 포함하였다.

# 1. 주식 투자전략 비교

KOSPI 200과 NASDAQ-100에서 투자전략별 성과와 거래비용의 영향을 비교하였다.

분석 기간: 2016.09.01~2026.08.31

비교 전략: B&H, Connors RSI(2), RSI + Bollinger, 모멘텀, Momentum + Price

모멘텀: 분기마다 과거 수익률 기준 상위 종목을 선정하여 동일 비중으로 투자

Momentum + Price: 기본 모멘텀에 시장 ETF 가격을 이용한 청산·재진입 규칙 추가

비교 지표: 연복리 수익률(CAGR), 최대 낙폭(MDD), Sharpe, 평균 투자 비중

기본 모멘텀은 코스피에서 B&H보다 수익률이 낮았고, 나스닥에서는 수익률이 소폭 높았으나 Sharpe는 낮았다. 가격 필터를 추가한 전략은 코스피의 기본 비용 조건에서는 개선 효과가 있었지만 높은 비용에서는 효과가 사라졌다. 나스닥에서는 가격 필터 추가 후 성과가 악화되었다.

# 2. 금리 변화에 따른 채권 분석

금리 변화가 가상의 채권 자산과 미래 지급 의무에 미치는 영향을 계산하고, 채권 비중 조정으로 손실을 줄일 수 있는지 살펴보았다.

데이터: 한국은행 ECOS 국고채 만기별 금리

분석 대상: 가상의 채권 포트폴리오와 30년간의 지급 현금흐름

시나리오: 전체 만기 금리의 상승·하락 및 단기·장기 금리가 서로 다르게 움직이는 경우

비교 방법: 자산·부채의 금리 민감도를 맞추는 방법과 설정한 시나리오의 최대 손실을 최소화하는 방법

두 방법이 선택한 30년물 비중은 각각 38.31%와 36.08%로 달랐다. 설정한 시나리오 내 최대 순자산 감소액은 초기 구성의 283.1억원에서 각각 36.4억원과 19.3억원으로 줄었다. 전체 만기의 금리가 같은 폭으로 움직일 때의 민감도를 맞추더라도, 만기별 금리가 다르게 움직이는 위험은 남는다는 점을 확인하였다.

실행 및 결과 확인

각 폴더의 README에서 데이터 출처, 가정, 실행 방법을 확인할 수 있다. 노트북에는 실행 결과를 저장하였으며, Google Colab에서 다시 실행할 수 있다. KOSPI 구성종목 조회에는 KRX 계정, 금리 데이터 조회에는 ECOS 인증키가 필요하다.

주식 분석은 과거 데이터의 가용성과 거래비용 가정에 영향을 받으며, 채권 분석은 가상 현금흐름과 선정한 금리 시나리오를 기준으로 하였다. 구체적인 한계는 각 프로젝트의 README에 정리하였다.
