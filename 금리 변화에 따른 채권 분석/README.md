# 금리 시나리오 기반 채권 포트폴리오 리스크 분석

## 프로젝트 개요

금리 변화가 채권 자산과 미래 지급 의무의 현재가치에 미치는 영향을 분석하고, 채권 비중 조정을 통한 순자산 변동 완화 효과를 검증하였다. 자산·부채관리(ALM) 관점에서 **순 DV01을 0으로 맞추는 방법**과 **선정한 금리 시나리오의 최대 손실을 최소화하는 방법**을 비교하였다.

분석 결과, 두 방법이 선택한 30년물 비중은 서로 달랐다. 평행 금리 변화에 대한 1차 민감도를 제거해도 비평행 금리 변화에 대한 위험은 남았으며, 여러 시나리오를 함께 고려하면 순 DV01을 일부 남기는 구성이 최대 손실을 더 줄였다.

대상 파일: `금리_시나리오_기반_채권_포트폴리오_리스크.ipynb`

본 프로젝트는 가상의 자산·부채를 이용한 기준일 스트레스 분석이다. 시간에 따른 매매 성과를 측정하는 백테스트는 포함하지 않았다.

## 데이터와 포트폴리오 설정

| 항목 | 설정 |
| --- | --- |
| 데이터 | 한국은행 ECOS 일별 시장금리, 통계표 `817Y002` |
| 조회 기간 | 2016-01-01~2026-09-10 |
| 관측 만기 | 국고채 1·3·5·10·20·30년 |
| 기준일 | 로딩한 데이터의 마지막 날짜; 저장된 결과는 2026-09-10 |
| 자산 현재가치 | 12,000억원 |
| 부채 현금흐름 | 1년차 말 1,000억원 지급, 이후 매년 3% 감소, 총 30년 |
| 부채 현재가치 | 약 11,875.0억원 |
| 초기 순자산 | 약 125.0억원 |

자산은 아래 가상 채권으로 구성하였다. 비중은 기준일 시장가치 기준이며, 모든 채권은 반기 이자 지급과 만기 원금 상환을 가정하였다.

| 채권 만기 | 연 쿠폰 | 초기 비중 |
| --- | ---: | ---: |
| 3년 | 3.0% | 25% |
| 5년 | 3.2% | 25% |
| 10년 | 3.4% | 30% |
| 30년 | 3.5% | 20% |

부채는 실제 보험상품이 아닌 가상의 감소형 지급 현금흐름이다. 실제 발행 채권의 종목별 가격과 계약별 보험부채를 사용한 것은 아니다.

## 분석 과정

1. **금리 데이터 수집**: 만기별 금리를 수집하고, 250개 관측치 전 대비 변화 분포를 계산하여 ±100bp 충격 크기를 과거 변화와 비교하였다.
2. **수익률곡선 추정**: Nelson–Siegel 모형을 사용하였다. 감쇠 파라미터를 격자 탐색하고, 나머지 계수는 최소제곱으로 추정하였다. 기준일 관측 금리 대비 RMSE는 약 2.0bp였다.
3. **현재가치·민감도 계산**: 자산과 부채 현금흐름을 할인하고, 평행 ±1bp 재평가로 DV01, 유효듀레이션, 컨벡서티를 계산하였다.
4. **스트레스 분석**: 금리 충격 후 자산·부채를 직접 재평가하여 순자산 변화를 계산하였다.
5. **DV01 매칭**: 총 자산 현재가치를 유지하면서 자산·부채의 순 DV01이 0이 되는 30년물 비중을 구하였다.
6. **1차·2차 효과 분해**: 평행 충격 손익을 듀레이션에 따른 1차 효과와 컨벡서티에 따른 2차 효과로 근사하고, 직접 재평가 결과와 비교하였다.
7. **최악손실 최소화**: 30년물 비중을 0~100% 범위에서 조정하여, 선정한 시나리오의 최대 순자산 감소액이 최소가 되는 비중을 구하였다. 전체 현금흐름 IRR도 함께 비교하였다.

비중 조정 시 나머지 자산은 3·5·10년물에 기존 상대 비율인 25:25:30으로 배분하였다. 따라서 최적화는 이 배분 규칙 안에서 30년물 비중 하나를 선택하는 문제이다.

## 금리 시나리오

| 시나리오 | 1년 금리 충격 | 10년 금리 충격 | 30년 금리 충격 |
| --- | ---: | ---: | ---: |
| 기준 | 0bp | 0bp | 0bp |
| 평행 상승 | +100bp | +100bp | +100bp |
| 평행 하락 | −100bp | −100bp | −100bp |
| Steepening | −50bp | 0bp | +50bp |
| Flattening | +50bp | 0bp | −50bp |

100bp는 1%p이다. 비평행 충격은 1·10·30년을 기준으로 구간별 로그만기 선형 보간하였다. 1년 미만은 1년 충격, 30년 초과는 30년 충격을 유지한다. NS 파라미터를 변경하는 대신 만기별 충격을 기준 곡선에 직접 더하였다.

## 주요 결과

### 1. DV01 매칭과 최악손실 최소화는 다른 비중을 선택하였다

| 지표 | 초기 구성 | DV01 매칭 | 최악손실 최소화 |
| --- | ---: | ---: | ---: |
| 30년물 비중 | 20.00% | 38.31% | 36.08% |
| 순 DV01, 억원/bp | −2.555 | 약 0 | −0.311 |
| 최대 시나리오 손실, 억원 | 283.1 | 36.4 | 19.3 |

최대 시나리오 손실은 기준 대비 순자산 감소액 중 가장 큰 값을 양수로 표시한 것이다. 선정한 시나리오와 배분 규칙 안에서 계산한 값이며, 모든 시장 상황에서의 최대 손실을 의미하지 않는다.

### 2. 평행 위험을 줄여도 비평행 위험은 남았다

아래 값은 충격 후 순자산에서 기준 순자산을 뺀 금액이다. 양수는 증가, 음수는 감소를 의미한다.

| 시나리오 | 초기 구성, 억원 | DV01 매칭, 억원 |
| --- | ---: | ---: |
| 평행 +100bp | +230.5 | +11.9 |
| 평행 −100bp | −283.1 | +17.3 |
| Steepening | +104.1 | −36.4 |
| Flattening | −104.1 | +54.9 |

초기 구성은 부채가 자산보다 금리에 민감하여, 금리가 하락하면 부채 가치가 더 크게 증가하고 순자산이 감소하였다. DV01 매칭 후 평행 충격의 순자산 변동은 줄었지만, Steepening에서는 손실이 남았다. 비중 조정에 따라 해당 비평행 충격의 손익 방향도 바뀌었다.

### 3. 평행 손익의 비대칭은 컨벡서티 차이로 대부분 설명되었다

| 구성 | 충격 | 1차 효과 | 2차 효과 | 1차+2차 | 직접 재평가 |
| --- | --- | ---: | ---: | ---: | ---: |
| 초기 | +100bp | +255.49 | −26.31 | +229.17 | +230.46 |
| 초기 | −100bp | −255.49 | −26.31 | −281.80 | −283.13 |
| DV01 매칭 | +100bp | 약 0 | +14.33 | +14.33 | +11.94 |
| DV01 매칭 | −100bp | 약 0 | +14.33 | +14.33 | +17.25 |

단위는 억원이다. 표시값은 각각 반올림하였다. 2차 효과는 자산·부채 각각의 현재가치에 컨벡서티를 곱한 값의 차이를 이용하였다. 초기 구성에서는 양 방향에 음의 2차 효과가 발생하여 이익은 줄고 손실은 커졌다. DV01 매칭 구성에서는 1차 효과가 제거되고 양의 2차 효과가 남았다. 근사와 직접 재평가 사이의 잔차에는 고차항과 수치미분 오차 등이 포함된다.

### 4. 위험 완화가 반드시 IRR 하락을 의미하지는 않았다

30년물 비중을 20.00%에서 DV01 매칭 비중인 38.31%로 조정했을 때, 전체 현금흐름의 반기복리 연율 IRR은 약 6.7bp 상승하였다. 해당 지표는 설정한 가격과 약정 현금흐름으로 계산한 내부수익률이며 실현 수익률이나 금리 충격 후 보유기간 수익률이 아니다.

## 실행 방법

1. Google Colab에서 `금리_시나리오_기반_채권_포트폴리오_리스크.ipynb`를 연다.
2. Colab 보안 비밀에 ECOS 인증키를 `ECOS_KEY`로 등록하고 노트북 접근을 허용한다. 코드의 환경변수 경로도 사용할 수 있다.
3. Google Drive를 연결하고 위에서부터 전체 셀을 실행한다.
4. 결과표와 그래프를 노트북에서 확인한다.

Google Drive 연결 시 금리 캐시는 `MyDrive/quant/cache/ktb_curve.parquet`에 저장된다. 새 데이터를 받으려면 로딩 호출을 다음과 같이 변경한다.


조회 기간을 변경하려면 `ecos_series()`의 날짜 설정도 함께 변경해야 한다. 결과표·그래프를 별도 파일로 자동 저장하는 기능은 포함하지 않았다. 한글 폰트 설치 셀은 Colab/Linux 환경을 전제로 한다.

## 가정과 한계

- **할인곡선**: 국고채 YTM 곡선을 현물금리 곡선으로 근사하였다. 엄밀한 무이표 할인곡선 구축 및 근사 오차 검증은 포함하지 않았다.
- **가상 현금흐름**: 실제 채권의 결제일·경과이자·일수계산을 모델링하지 않았다. 부채는 매년 지급액이 감소하는 구조이며 해약환급금, 사망률, 보증·옵션, 신계약 등을 제외하였다.
- **분석 시점**: 기준일의 즉시 평가 변화를 분석하였다. 기간 경과, 재투자, 동적 리밸런싱, 거래비용, 신용·유동성 위험은 포함하지 않았다.
- **최적화 범위**: 최소 손실 비중은 선정한 시나리오와 고정된 배분 규칙에 의존한다. 시나리오를 이용한 최적화 결과이며 별도 미관측 시나리오 검증은 포함하지 않았다.
- **데이터 처리**: 결측치를 직전 값으로 채우며 채움 기간 제한이 없다. 캐시의 기간·최신성 검증도 보완이 필요하다. 중첩된 250관측치 금리 변화 분포를 독립 표본이나 미래 발생 확률로 해석하지 않는다.

## 사용 도구
